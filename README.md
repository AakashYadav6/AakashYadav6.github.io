# GitHub Pages Portfolio

This is a static single-page portfolio inspired by premium section-based portfolio sites.

## Customize

1. Open `script.js` and replace the placeholder `portfolio` data with your real name, role, experience, projects, links, and contact info.
2. If you want to adjust colors or spacing, edit `styles.css`.
3. If you want to change the layout structure, edit `index.html`.

## Deploy to GitHub Pages

1. Push these files to your `username.github.io` repository.
2. If the repo is already configured for GitHub Pages, the site will publish automatically.
3. Your portfolio will then be available at `https://username.github.io`.
